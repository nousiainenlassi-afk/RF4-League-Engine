# RF4 League Engine

RF4 League Engine is a Python package for generating league data, schedules, and formatted output for RF4-based competitions.

## Project layout

- `src/rf4lg/` — package source code
- `data/` — season and input data files
- `output/` — generated league output
- `tests/` — unit and integration tests

## Getting started

```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .
```

## Usage

Import `rf4lg` or run package modules directly once implemented.
